# Pixel Mapper for Windows

Live pixel mapping for stage and event lighting.
GDTF fixtures · MVR import · MA3-style selection grid and groups · effects · positions · timecode · Art-Net / sACN output (MADRIX LUNA ready).

## ⬇ Download

**[Download Pixel Mapper (Windows 10/11, 64-bit)](https://github.com/QTechnologies-Sl/pixel-mapper-releases/releases/latest)**

Open the link, then click **PixelMapper-Setup-x.x.x.exe** under *Assets*.

## Install
1. Run **PixelMapper-Setup-x.x.x.exe**.
2. If Windows says *"Windows protected your PC"*, click **More info → Run anyway**.
3. Open **Pixel Mapper** from the Desktop or the Start menu.
4. The first time, allow it in the Windows Firewall pop-up (tick **Private** and **Public**) so Art-Net / sACN can reach your nodes.

Your shows and library live in **Documents\Pixel Mapper** (`showfiles`, `library\fixtures`, `videos`, `graphics`, `mvr`).
